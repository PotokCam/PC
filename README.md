# PotokCam 📷

**PotokCam** turns your smartphone into a professional webcam for streaming, video calls, and recording. Get studio-grade video quality, advanced controls, and seamless connection — all from the device you already own.

🌐 **[Official Website & Download](https://potokcam.vercel.app)**

## Versions / Версии

We provide two versions for Windows:
* **MFVC Version**: Optimized for Windows 11 using modern system APIs for the best performance.
* **Legacy Version**: Universal version for older Windows systems (requires OBS Studio).

Мы предоставляем две версии для Windows:
* **Версия MFVC**: Оптимизирована для Windows 11 с использованием современных системных API для максимальной производительности.
* **Версия Legacy**: Универсальная версия для старых систем Windows (требует использования OBS Studio).
